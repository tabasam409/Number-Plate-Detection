# 🚗 Automatic Number Plate Detection (ANPR)

## Description
An Automatic Number Plate Recognition (ANPR) system that detects and reads vehicle license plates from images using computer vision and OCR techniques.

## Technologies Used
- Python
- OpenCV
- Tesseract OCR / EasyOCR
- NumPy
- Matplotlib
- Jupyter Notebook

## How to Run
1. Clone the repository:
   ```
   git clone https://github.com/tabasam409/Number-Plate-Detection.git
   cd Number-Plate-Detection
   ```
2. Install dependencies:
   ```
   pip install opencv-python numpy matplotlib easyocr jupyter
   ```
3. Open the notebook:
   ```
   jupyter notebook Number_Plate_Detection.ipynb
   ```

## Project Structure
- `Number_Plate_Detection.ipynb` - Main notebook with plate detection and OCR code
